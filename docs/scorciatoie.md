# Scorciatoie da tastiera

Datini usa le stesse scorciatoie di Outlook in italiano. Su macOS, al posto di **Ctrl** si può usare anche **Cmd**.

Le scorciatoie che agiscono su un messaggio (rispondere, eliminare, contrassegnare...) funzionano quando non stai scrivendo in un campo di testo, così non disturbano la digitazione.

## Posta

| Azione | Scorciatoia |
|---|---|
| Nuovo messaggio | Ctrl+N |
| Rispondi | Ctrl+R |
| Rispondi a tutti | Ctrl+Maiusc+R |
| Inoltra | Ctrl+F |
| Elimina | Canc |
| Archivia | Backspace |
| Contrassegna o togli il contrassegno | Ins |
| Segna come letto | Ctrl+Q |
| Segna come da leggere | Ctrl+U |
| Messaggio successivo o precedente | Freccia giù / Freccia su |
| Invia e ricevi | F9 |
| Cerca | Ctrl+E |
| Chiudi il menu File o le impostazioni | Esc |

## Mentre scrivi un messaggio

| Azione | Scorciatoia |
|---|---|
| Invia | Ctrl+Invio |
| Scegli un indirizzo suggerito | Freccia giù / Freccia su, poi Invio o Tab |
| Aggiungi l'indirizzo scritto | Invio, virgola o punto e virgola |
| Togli l'ultimo destinatario | Backspace nel campo vuoto |
| Chiudi la finestra (il messaggio resta in Bozze) | Esc |

## In arrivo

Queste scorciatoie di Outlook arriveranno con le funzioni a cui servono:

| Azione | Scorciatoia |
|---|---|
| Sposta in una cartella | Ctrl+Maiusc+V |
| Posta, Calendario, Contatti, Attività | Ctrl+1 … Ctrl+4 |
| Grassetto, Corsivo, Sottolineato | Ctrl+G, Ctrl+I, Ctrl+S |
